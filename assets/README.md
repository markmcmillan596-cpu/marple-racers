# Assets

Milestone 1 uses original placeholder artwork drawn in Lua by the renderer.
Store future textures, fonts, and audio in this directory.

## Kitchen Table Circuit

The checked-in Lua drawing source at `kitchen/art.lua` is the original artwork
for the dressed track. Maple grain, gingham, the printed saucer, napkin, citrus,
juice, cutlery, blueberries, and sugar bowls are complete for Milestone 5.
Object placement and collision dimensions live in `tracks/kitchen.lua`.

For future polish, review contrast in a manual Windows playtest and refine the
small prop silhouettes if they become difficult to read at the minimum window size.
